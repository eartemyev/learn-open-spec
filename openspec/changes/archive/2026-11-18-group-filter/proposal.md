# Proposal

## Why

Администратору нужно по одному проверять доступ восьми сотрудников подрядной студии «Северная». Общий список сотрудников заставляет каждый раз искать имя среди остальных; выбор группы сократит список до нужной команды.

## What Changes

- Добавить перед полем «Сотрудник» на экране проверки доступа одиночный фильтр «Группа» с вариантом «Все группы» по умолчанию.
- Показывать в списке сотрудников только участников выбранной группы по их `groupIds`; при снятии фильтра возвращать всех сотрудников, включая сотрудников без групп.
- Сохранять выбранного сотрудника, если он остаётся в списке, иначе сбрасывать выбор и результат проверки. Выбранный сервис при смене группы сохранять.
- Для группы без участников показывать сообщение «В этой группе нет сотрудников» и оставлять сотрудника невыбранным.
- Пересчитывать доступ по всем разрешениям выбранного сотрудника, включая разрешения других его групп. Фильтр действует только на выбор сотрудника для проверки доступа.
- При замене конфигурации согласовывать фильтр и выбор сотрудника с новыми группами и членством; сбрасывать выбранный сервис, если его больше нет. Фильтр хранить только в состоянии экрана.

## Capabilities

### New Capabilities

- `employee-selection`: выбор сотрудника для проверки доступа, фильтрация по группе, согласованность выбора и поведение при обновлении конфигурации.

### Modified Capabilities

Нет. Требования `access-calculation` и `config-import` сохраняются; новая спецификация описывает поведение интерфейса поверх них.

## Impact

- `src/components/App.tsx`: фильтр группы, производный список сотрудников, согласование выбора и пустое состояние.
- `src/components/App.test.tsx` и проверки импорта в `src/components/Permissions.test.tsx`: сценарии выбора, полных источников доступа и замены конфигурации.
- Модель `User.groupIds` и `Config.groups` уже поддерживает нужное членство. Данные поступают через `useSimulator`; новые зависимости, сервер, сетевые запросы и изменения формата конфигурации не нужны.
- Создание сотрудников и групп, добавление студии в учебные данные, фильтрация панели разрешений и сохранение фильтра между загрузками находятся за пределами изменения.
