# Tasks

Реализацию вести скиллом `tdd` согласно `AGENTS.md`: каждый сценарий сначала воспроизвести падающим тестом, затем добавить минимальную реализацию и выполнить рефакторинг. Поведение задано в `specs/employee-selection/spec.md`, технические решения — в `design.md`.

## 1. Фильтрация списка сотрудников

- [x] 1.1 Через TDD добавить в `App.tsx` поле «Группа» перед «Сотрудник», значение «Все группы» по умолчанию и отбор по членству. В `App.test.tsx` проверить восемь участников «Северной», исключение посторонних, исходный порядок и вариант «Не выбран»; данные подготовить в тесте через существующий формат конфигурации.
- [x] 1.2 Через TDD покрыть снятие фильтра, сотрудников без групп, несколько групп одного сотрудника, повтор членства и конфигурацию без групп. Проверить точный состав вариантов поля «Сотрудник» и отсутствие дублей в `App.test.tsx`.

## 2. Согласованность выбора и результата

- [x] 2.1 Через TDD согласовать выбор сотрудника при смене группы: сохранить остающегося участника, иначе сбросить его без автоматической замены, сохранить сервис. В `App.test.tsx` проверить исчезновение прежних результата и источников, приглашение выбрать сотрудника и отсутствие восстановления сброшенного выбора при снятии фильтра.
- [x] 2.2 Через TDD добавить сообщение «В этой группе нет сотрудников» для пустой группы. В `App.test.tsx` проверить единственный вариант «Не выбран», приглашение проверки и исчезновение сообщения при переходе к группе с участниками или «Все группы».
- [x] 2.3 Через TDD подтвердить полную проверку доступа при активном фильтре: в `App.test.tsx` проверить прямой источник и источник другой группы сотрудника. Добавить проверку полноты панели разрешений и вариантов формы выдачи; передавать исходную конфигурацию и использовать существующий `checkAccess`.

## 3. Обновление конфигурации и временное состояние

- [x] 3.1 Через TDD согласовать выбранную группу и сотрудника после успешного импорта: проверить в `Permissions.test.tsx` удаление группы с переходом в «Все группы», удаление сотрудника, потерю членства, удаление выбранного сервиса со скрытием результата, опустевшую группу и сохранение действительного выбора с обновлёнными именами и разрешениями.

Проверить сценарий в `Permissions.test.tsx` и сохранить существующее поведение отказа импорта, включая фильтр, выбор, результат и сохранённую конфигурацию.
- [x] 3.3 Через TDD проверить неизменность экспорта и сохранённой конфигурации при смене фильтра и сотрудника, а также сброс фильтра в «Все группы» при повторном монтировании экрана. Подтвердить сценарии в компонентных тестах без изменений формата файла и учебных данных.
